\# ShellConsole

Android 平台本地 Shell 终端工具，基于 Kotlin + Jetpack Compose 开发。



\## ✨ 项目简介

ShellConsole 是一款安卓端本地命令行控制台App。

可以直接在安卓设备内执行 Linux shell 命令，查看系统信息、调试设备、读取文件、执行简单脚本。

项目采用 Jetpack Compose 完全声明式UI，界面简洁轻量化，适配手机与平板。



> ⚠️ 声明：本项目仅用于安卓学习与开发调试，请勿用于非法用途。



\## 📋 功能清单

\- ✅ 交互式 Shell 命令输入与执行

\- ✅ 命令输出实时回显，支持长文本滚动查看

\- ✅ 命令历史记录，支持上下键快速调取历史指令

\- ✅ 自定义终端字体大小

\- ✅ 深色/浅色主题切换

\- ✅ 查看设备系统版本、CPU、内存等硬件信息

\- ✅ 文件目录浏览，查看目录下文件列表

\- ✅ 支持基础 linux 命令：ls, pwd, cat, df, top 等



\## 🛠️ 开发环境

\- 开发语言：Kotlin

\- UI框架：Jetpack Compose

\- 构建脚本：Gradle Kotlin DSL (build.gradle.kts)

\- 最低 Android SDK：24 (Android 7.0 Nougat)

\- 推荐编译环境：Android Studio Hedgehog / Iguana
